# Salon Automation System

A full-stack web application to automate salon appointment booking, allowing customers to schedule, view, and manage salon appointments online.

## Features

- Book salon appointments online
- View and manage existing appointments
- Separate backend for handling appointment data and scheduling logic

## Tech Stack

**Frontend:** React.js (Vite), CSS
**Backend:** Node.js, Express.js
**Other:** JavaScript, HTML

## Project Structure

```
Salon/
├── src/          # React components and pages
├── public/       # Static assets
├── backend/      # Node.js/Express API
├── salonads/     # Additional module
├── index.html
├── package.json
```

## Getting Started

### Prerequisites
- Node.js installed on your machine

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/ABISRI22/Salon.git
   cd Salon
   ```

2. Install frontend dependencies
   ```bash
   npm install
   ```

3. Install backend dependencies
   ```bash
   cd backend
   npm install
   ```

4. Start the backend server
   ```bash
   npm start
   ```

5. Start the frontend (from the project root)
   ```bash
   npm run dev
   ```
